# UI/UX Pro Max Enterprise Standard

## Core Guidelines

1. **Low Friction Fast Workflows**:
   - Telephony sales workflow: Read lead -> Copy phone (1-click) -> Call -> Log outcome -> Next contact. Minimal clicks, zero reload latency.

2. **Contextual Empty States & Skeleton Loading**:
   - No generic "No data" placeholders. Give actionable, concise guidance.
   - Smooth skeleton animations that mirror table columns without jarring layout shifts.

3. **Bidirectional (RTL/LTR) Design Parity**:
   - Arabic layout must feel natively designed, not just machine-flipped.
   - Phone numbers and email addresses remain strictly `dir="ltr"` inside Arabic layout.
