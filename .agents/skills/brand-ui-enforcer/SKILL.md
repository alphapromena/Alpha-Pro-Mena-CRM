# Brand UI Enforcer — Alpha Pro MENA

## Mandatory Brand Compliance Rules

1. **Logo is a Brand Asset, Not a Theme Component**:
   - The Alpha Pro MENA logo colors MUST NEVER be dynamically altered by theme selection.
   - Do NOT apply CSS filters (`invert`, `hue-rotate`, `grayscale`, dynamic SVG fill tinting) to the logo mark or typography.
   - Adjust surrounding container background if needed for legibility — NEVER change official logo colors.

2. **Official Brand Typography**:
   - Primary English: `Barlow` (700/800 for headers, 500/600 for body).
   - Primary Arabic: `Cairo` (700/800 for headers, 500/600 for body).
